# EasyEats

An inclusive food ordering system built using Streamlit.

## Features
- Self Ordering Mode
- Parental Mode with Spend Limit Control
- Elder Mode Simplified UI
- Wallet System
- Order Tracking Simulation
- SQLite Database Storage

## Run Locally

1. Create virtual environment
2. Install requirements
3. Run:

streamlit run app.py

## Deploy
Upload to GitHub and deploy using Streamlit Cloud.
